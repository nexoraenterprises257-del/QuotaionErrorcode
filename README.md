# Smart Quote Master

Enterprise Quotation Management System

Create a professional quotation management web application for Immense Smart Solution.

The application should allow me to generate enterprise quotations without editing PDFs manually.

Main Requirements

Dashboard

 Simple and clean interface

 Show all quotation sections

 One-click Generate PDF button

Client Information

Create editable fields:

 Client Name

 Company Name

 Proposal Number

 Date

Product Pages

Each product should be an independent quotation page.

Products:

 Bulk SMS

 RCS Business Messaging

 WhatsApp Business API

 OBD Voice Calls

 IVR Solutions

 SMPP Connectivity

Requirements:

 Enable/Disable each product using a checkbox or toggle.

 Disabled products must not appear in the final PDF.

 Enabled products must automatically appear in the quotation.

Example:
If I enable only Bulk SMS and WhatsApp Business API, the PDF should contain only those two product pages.

Pricing

For every product create editable fields:

 Setup Charges

 Monthly Charges

 Price

 GST

 Final Total

Everything must be editable.

Account Manager

Create editable fields:

 Name

 Designation

 Mobile Number

 Email Address

These details should automatically appear on the last page.

PDF

Create a Generate PDF button.

Requirements:

 Export professional A4 PDF.

 Keep the quotation layout exactly like the original template.

 Include only selected product pages.

 Download the PDF.

UI

Use a premium corporate UI.

Theme:

 White

 Dark Blue

 Light Grey

Responsive design.

Use modern cards, professional forms and smooth animations.

Technology

Use:

 Firebase Studio

 React

 Tailwind CSS

 Firebase Hosting

No authentication required.

Everything should work inside a single web application.

Important: I will upload my existing quotation PDF later. The application must use that PDF as the design template and make only the required fields editable while preserving the original layout.

Use this PDF as the exact design template. Do not redesign or change the layout. Keep fonts, spacing, colors, and page structure exactly the same. Only make the specified fields editable and generate the PDF in the same design
